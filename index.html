Keyboard Shortcuts

  • Ctrl + B / I / U : Bold, Italic, Underline
  • Ctrl + S : Download & Save Note
  • Ctrl + P : Print / Save to PDF
  • Alt + T : Create New Tab
  • Alt + W : Close Current Tab
  • Alt + PageUp / [ / , : Switch to Previous Tab
  • Alt + PageDown / ] / . : Switch to Next Tab
  • Alt + M : Open File Menu
  • Alt + F : Open Text Settings (Font / Size)
  • Alt + O : Open Outline Panel
  • Alt + R : Read Aloud (Play / Stop)
  • Alt + V : Open Voice Selection Menu
  • Alt + N : Normal Text (Clears H2/H3)
  • Alt + H : Apply Heading 2 (H2)
  • Alt + J : Apply Heading 3 (H3)
  • Alt + 1 / 2 / 3 / 4 : Apply Highlight Color
  • Alt + 0 : Remove Highlight Color
  • Alt + 5 : Eraser (Strip all formatting)
  • Alt + D : Insert Current Date & Time
  • Alt + K : Render selection / tab as Markdown
  • Alt + = / Alt + - : Increase / Decrease text size
  • Alt + Z : Toggle Zen Mode (Hide all menus)
  • Esc : Close menus / return to typing
  • Ctrl + Shift + ? : Show this menu
